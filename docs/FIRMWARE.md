# Package variants / Variantes du paquet

Compatible with **PS5 and PS5 Pro** (jailbroken consoles).

Unzip both archives. Start with `Kart-PS5-candidate/PPSA99611/` from `Kart-PS5.zip`. In `Backport.zip`, select the folder matching your exact firmware, such as `Backport-candidate/FW_11.60/PPSA99611/`, and copy its **`eboot.bin` and `sce_sys/param.json`** over those two files in the main application folder. The variant is an overlay, not a standalone application: keep the shaders, icon, and other common files from the main package. Supply your own matching signed `sce_module/libc.prx` and PAL `DATA` tree; Sony libraries and game files are not distributed; see [Getting your own libc.prx](LIBC_EXTRACTION.md). Check that `PPSA99611/portable.txt` exists (create an empty file if missing): the original `v1.0.0-rc1` archive omitted this required marker. Copy only the resulting `PPSA99611/` folder into `/data/`. Add `/data/PPSA99611` to `/data/shadowmount/manual.lst`; ShadowMountPlus 1.6beta16 does not scan `/data` itself by default.

Compatible avec **PS5 et PS5 Pro** jailbreakées.

Décompresser les deux archives. Partir de `Kart-PS5-candidate/PPSA99611/` dans `Kart-PS5.zip`. Dans `Backport.zip`, choisir le dossier du firmware exact de la console, par exemple `Backport-candidate/FW_11.60/PPSA99611/`, puis copier **son `eboot.bin` et son `sce_sys/param.json`** à la place de ces deux fichiers dans le dossier de l'application. La variante est une superposition, pas une application complète : conserver les shaders, l'icône et les autres fichiers communs du paquet principal. Ajouter sa propre bibliothèque signée `sce_module/libc.prx` adaptée au firmware et les données PAL `DATA` ; les bibliothèques Sony et les fichiers du jeu ne sont pas distribués ; voir [Obtenir son propre libc.prx](LIBC_EXTRACTION.md#obtenir-son-propre-libcprx). Vérifier que `PPSA99611/portable.txt` existe (le créer vide si absent) : la première archive `v1.0.0-rc1` omettait ce marqueur requis. Copier uniquement le dossier `PPSA99611/` obtenu dans `/data/`. Ajouter `/data/PPSA99611` à `/data/shadowmount/manual.lst` ; ShadowMountPlus 1.6beta16 ne surveille pas directement `/data` par défaut.

No separate disc files or personal saves are included. Embedded code/data remains in the recompiled executable. Aucun fichier disque séparé ni sauvegarde personnelle ne sont inclus ; le binaire recompilé conserve son code et ses données intégrés.
